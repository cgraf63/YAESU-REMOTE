SAVED NETWORKS best first · the box uses the first one in range

Example: home router first, phone hotspot second - at home the box takes the router, on the road the phone. The setup network YAESU-REMOTE always stays last, so the box can always be reached again.

PHONE NOTIFICATION (NTFY)

Subscribe to the same topic in the ntfy app. Whenever the box gets a new address you get “YAESU-REMOTE online - 192.168.x.x”; a tap opens the remote. Useful on Android, where .local names often do not open in the browser.

FIRST START

Turn on a phone hotspot named YAESU-REMOTE with the password yaesu-remote. The box joins it, the phone shows it under connected devices. Open http://yaesu-remote.local or the address shown there, add your networks here.

Alternative: a file wifi.txt on the boot drive of the SD card (readable on every PC) with lines ssid=… and password=…, one pair per network, best first. The box imports it at start and removes the passwords from the file.
