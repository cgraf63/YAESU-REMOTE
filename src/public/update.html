HOW IT WORKS

        

            
The box checks GitHub a few minutes after the start and then every 12 hours; CHECK NOW asks at once. Only what changed is downloaded - a phone hotspot is fine.

            
INSTALL UPDATE takes about a minute: new code, build, restart. The remote page is gone for that time and comes back by itself; the OLED shows UPDATE. If the new version does not build, the box goes back to the old one. Not while the radio is transmitting.
